# Россия · основные сервисы

Reviewed on 2026-10-04. Add through **Правила → Готовые правила → Россия · основные сервисы**. Nothing is applied automatically.

The preset contains 18 VPN rules: GeoSite sets for YouTube, Discord, WhatsApp, Telegram, Instagram, Facebook and X; Telegram IP networks; domain suffixes for Signal, Viber, Bluesky and Roblox; and six Windows application-name rules for Discord, WhatsApp, Telegram, Signal, Viber and Roblox. Existing specific Direct exceptions retain their execution priority. Reapplying the set adds no duplicates.

Selection is based on measured or reported restrictions, which may differ by network, region and service feature. [Access Now's 2025 primary report](https://www.accessnow.org/wp-content/uploads/2026/03/KeepItOn-Internet-Shutdowns-2025-Annual-Report.pdf) covers restrictions affecting messaging and video platforms in Russia. OONI documents [Discord blocking](https://explorer.ooni.org/findings/2025-russia-blocked-discord), [Signal interference](https://github.com/ooni/ooni.org/issues/1680), [Bluesky blocking](https://explorer.ooni.org/findings/2026-russia-blocked-bluesky), and [social platform blocking](https://ooni.org/documents/russia-military-conflict-ru.pdf). This is a useful service selection, not a claim that every listed feature is blocked on every ISP today.

Signal suffixes follow its [official firewall guidance](https://support.signal.org/hc/en-us/articles/360007320291-Firewall-and-Internet-settings). [Viber's desktop guidance](https://help.viber.com/hc/en-us/articles/8805123374365-Open-ports-for-Viber-desktop) and [Roblox's firewall guidance](https://en.help.roblox.com/hc/en-us/articles/203312840-Firewall-and-Router-Issues) explain why domain-only routing is insufficient for some desktop connections; application rules cover those flows in TUN. Domain selection was cross-checked against the maintained source lists for [Viber](https://github.com/v2fly/domain-list-community/blob/master/data/viber) and [Roblox](https://github.com/v2fly/domain-list-community/blob/master/data/roblox). Existing GeoSite/Telegram networks remain the pinned embedded snapshots documented in [geo sources](../resources/geo/README.md).

Application rules require TUN. Calls, games, federated Bluesky hosts, browser DoH/ECH, new CDN domains and provider changes may need a specific additional rule or Entire PC mode. A preset cannot override a suspended account or a service's billing restrictions; for example, [Notion's own Russia account restrictions](https://www.notion.com/help/restrictions-for-customers-based-in-russia) remain separate from network reachability. Existing OpenAI/Claude/other service presets remain available individually; the Russia set does not send all Google services or all .ru domains through VPN.
