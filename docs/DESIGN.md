# Night Track

The main screen follows the user's selected third concept: a midnight-blue dashboard with the existing running snowman mascot. From 0.1.17 the hero contains a native world map instead of the alpine illustration, matching the mobile map while keeping the dashboard's existing layout. The sidebar, controls, cards, settings and dialogs share a restrained blue palette. Active navigation uses a slim marker; the primary connection action remains large and explicit.

Connection state, selected server, routing mode, TUN/Proxy switches, traffic measurements and server rows are native WPF bindings. Traffic charts display up to 120 measured samples per direction; repeated timestamps are ignored, and disconnection clears the Windows history. They have no independent timer. Android retains the last session's charts until the next connection and accumulates received/sent GB across rule reloads.

The table includes the subscription, protocol, ping and favorite action. Card layout remains available. Home keeps navigation from the selected server, the routing-mode chooser, clickable ping and a scrollable list of servers from all subscriptions. Home uses one virtualized scroll surface containing the overview and every server row. The shared toolbar wraps onto two rows at narrower widths. The selected server and routing mode share geometry and hover styling. Public VPN IP and the physical uplink’s local/private IP are labelled separately; the local address tooltip lists adapter and IPv4/IPv6 addresses. No synthetic server-load data is displayed.

The blue theme is adopted once when migrating existing settings. Subsequent custom accent selections persist. OLED, Windows reduced-motion preferences and the app's animation/glow switches remain supported. Loading rotation and connection motion stop when hidden, minimized, unloaded or covered by a modal dialog.

The hero map embeds the same simplified public-domain Natural Earth geometry as Android (`android/app/src/main/assets/world.json`). Projected country geometry is cached; the luminous signal animates independently without rebuilding the map each frame. The origin comes from an optional approximate ordinary-IP lookup through ipwho.is; GPS is not requested and coordinates are not saved. Windows only fetches before connecting; Android binds the request to a validated non-VPN network. Without a response there is no fabricated arc origin. The server endpoint denotes a country center, not the physical data center's exact coordinates.

The earlier alpine hero's built-in ImageGen prompt and references remain recorded in `resources/design/night-track.asset.json`. The sidebar scenery uses native vector geometry, and the application/sidebar/tray/installer/hero icon uses the existing white/blue mascot in a dark navy trilby; its built-in ImageGen edit prompt is recorded in `resources/icons/snowman.asset.json`. `scripts/build-icon.ps1` converts that PNG to a seven-size ICO.

The WPF smoke harness renders disconnected, connecting, connected and error states, English and minimum-window layouts, all pages and the shared dialogs. Its fixtures use isolated storage and do not install or connect a live VPN.
Rules show newest entries first without changing execution priority. The priority view retains drag reordering; entries without a creation timestamp retain their relative legacy priority. The [client review](CLIENT-REVIEW.md) records the source-backed behavior decisions. Settings uses the shared regular gear geometry, and the 76px sidebar keeps its logo/glow and status badge within bounds.

Version 0.1.15 adds the same dark navy trilby to the hero snowman, preserving the illustration's scene, composition and white/blue palette. WPF uses process-local software rendering from startup for the dashboard and dialogs to avoid dependence on a GPU surface when restoring the window. The root client-area surface has an explicit opaque theme background. The tray Open action preserves maximized state and requests repaint after showing the window.

## Windows 0.1.18 map and live latency

The Home hero is 294 px high. Country geometry uses a larger projection with latitude-aware route fitting; the original destination, real-IP departure and traveling blue signal remain connected to the map. The connection-state dot now sits beside «Ваше подключение» with a status tooltip, instead of floating independently over a country. Existing status/action and mascot styling remain intact.

A full ping scan selects latency sorting. Completed results reorder visible rows during the scan, coalesced over 120 ms, without changing the selected server or clearing/recreating the entire server collection. Successful green results precede slower amber/red and unknown results. Windows HTTPS probes now measure one cold request (DNS/VPN/TLS/HTTP), with six bounded concurrent probes and the same five-second active deadline. The earlier median of three HTTP requests both prolonged scanning and mixed cold and reused-connection timings. Probe startup and owned process cleanup run off the WPF dispatcher so OS waits cannot freeze sorting or animation.
