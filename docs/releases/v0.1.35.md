# Bebekon VPN для Windows 0.1.35

Исправлен сбой запуска и удаления Windows-службы после импорта Zapret. Для проблемной установки 0.1.34 запустите новый Setup в ту же папку. Если цель — удалить клиент, снимите галочку запуска в конце установки и удалите Bebekon через список установленных приложений Windows.

## Причина сбоя

Импорт копировал пакет в `%ProgramData%\BebekonVPN\zapret`. Проверка хранилища службы разрешала только файлы на первом уровне. Работающая служба могла использовать импорт до следующего запуска. При перезапуске проверка выбрасывала исключение ещё до подключения к диспетчеру служб Windows. Та же проверка выполнялась при очистке WFP. Удаление файлов из Program Files и установка той же версии оставляли проблемную папку на месте.

Отказ Setup в создании временной папки профиля Windows возникает при распаковке установщика. У этого сообщения отдельная причина. Для него нужно проверить доступ к указанному временному каталогу под учётной записью, запускающей Setup.

## Что происходит с Zapret

- Подтверждённый администратором импорт копирует исполняемые файлы, библиотеки, драйвер, списки и поддерживаемые профили из выбранной локальной папки. Код читает параметры запуска из `general*.bat`. За выбор доверенного исходного пакета отвечает администратор. Контрольные суммы обнаруживают изменения после импорта.
- У службы и администраторов есть доступ к рабочей копии. Проверяются владельцы, права и отсутствие перенаправлений в рабочем дереве. Рядом с активной копией допускаются временная и предыдущая версии той же структуры. После обрыва в момент замены служба может восстановить предыдущий импорт.
- Служба запускает собственный `winws.exe` в Windows Job Object и освобождает его при остановке. Уже запущенный сторонний `winws` вызывает сообщение о конфликте. Исходная папка пользователя и отдельная установка Zapret находятся вне области очистки.
- Подбор профиля проверяет доступность выбранных сайтов через прямое подключение. Этот тест измеряет только проверенные обращения. Результат зависит от сети и версии импортированной сборки.
- Начиная с 0.1.35 запуск профиля сохраняет текущую системную настройку TCP timestamps. Эффективность профилей с `fooling=ts` зависит от этой настройки. Версия 0.1.34 могла включить timestamps без сохранения предыдущего значения. Восстановить историческое значение автоматически невозможно.
- WinDivert загружает драйвер по запросу приложения. Если Windows удерживает файл драйвера, закройте использующее его приложение, перезагрузите Windows и повторите удаление. [Документация WinDivert](https://reqrypt.org/windivert-doc.html)

## Порядок удаления

1. Выйдите из клиента через меню в трее. Установщик проверяет, остался ли запущенный клиент. Для системного прокси при наличии сохранённой копии используется профиль владельца VPN. При повышении прав под другим пользователем может понадобиться закрыть прокси-сеанс из исходной учётной записи.
2. Сценарий временно отключает запуск службы и останавливает её. Модуль очистки удаляет правила DNS с меткой Bebekon и фильтры двух собственных провайдеров WFP. Эта операция работает и при утрате регистрации службы, пока доступен исправный модуль очистки.
3. После сетевой очистки удаляется проверенное машинное хранилище, включая импорт Zapret, журналы и служебные файлы. Затем удаляются служба, её параметры, запись автозапуска из загруженного профиля и защищённая portable-копия при её наличии.
4. Setup удаляет установленные файлы и предлагает удалить подписки, правила и настройки владельца. При подавлении диалогов пользовательские данные сохраняются по умолчанию.

Если файлы программы удалили вручную, восстановите их установкой 0.1.35 и повторите штатное удаление. При ошибке новый деинсталлятор сообщает этап. Например, ошибка 21 относится к сетевой политике, 22 — к файлам в ProgramData. После успешного удаления команда `sc.exe query BebekonVPN` возвращает 1060.

## Приёмка на отдельной Windows

Для полной проверки релиза нужны установка Setup поверх 0.1.34 с импортом, перезагрузка, запуск из обычной учётной записи и удаление через системный список программ. Проверяются отсутствие службы, каталога службы и собственных правил DNS/WFP, сохранность исходной папки Zapret, выбор сохранения или удаления пользовательских данных и системный прокси до и после сеанса. Отдельные случаи — работающий внешний WinDivert, удалённая регистрация службы, повторный запуск очистки и повышение прав под другой учётной записью.
