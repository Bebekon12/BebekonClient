# Bebekon VPN для Windows 0.1.29

- На странице «Серверы» появились отдельные кнопки проверки списка и остановки. Счётчик показывает завершённые замеры и количество серверов без ответа. Массовая HTTPS-проверка обрабатывает по два сервера и пропускает неподдерживаемые конфигурации. Определение страны больше не задерживает эту очередь.
- В разделе «Защита → Блокировать выбранные адреса без VPN» можно сохранить домены с поддоменами, отдельные IP и подсети CIDR. Кнопка «Выключить» сохраняет список для следующего включения. Для подключения с активной защитой требуется TUN. Изменение активного списка переподключает работающий туннель.
- Для выбранных доменов служба задаёт целевую DNS-политику Windows. Пока туннель работает, sing-box выдаёт защищённые виртуальные адреса и отправляет эти соединения через VPN. Постоянные фильтры WFP блокируют прямой выход к виртуальным адресам, туннельному DNS и перечисленным IP. При остановке приложения, ядра или службы эти фильтры остаются в Windows.
- Доменная защита действует для приложений, использующих системный DNS. Для приложений с собственным DNS, сторонним прокси или ранее закешированными реальными адресами укажите IP/CIDR назначения либо используйте защиту всего приложения. Виртуальные диапазоны доменной защиты — `198.19.0.0/16` и `fd84:be:be:1::/96`.
- В «Настройки → Сеть → Обход замедления сайтов без VPN → Списки и QUIC» доступны списки включений и исключений для прямого трафика. Запись `^example.org` задаёт только точное имя. При включённой опции «Предпочитать TCP» Bebekon отклоняет распознанный QUIC на UDP/443 в выбранной области. Переход на TCP зависит от приложения.
- Списки можно импортировать из папки Obhod. Для работы с оригинальным WinDivert предусмотрен отдельный пункт «Obhod · WinDivert»: выбор установленной папки, запуск выбранного внешнего профиля, редактор списков и доступ к штатному управлению службой. Внешний профиль имеет собственную системную область действия.

Версия Android в общем канале — 0.1.13.
