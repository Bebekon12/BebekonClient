# Bebekon VPN · Windows 0.1.24 и Android 0.1.11

Обновление стабильности сети. Подписки, правила и настройки сохраняются при установке поверх прежней версии; ключи подписи не менялись.

Скачайте нужный файл:

- **Windows:** `BebekonVPN-0.1.24-Setup-x64.exe` — обычная установка или обновление.
- **Android 10+:** `Bebekon-Android.apk` — один универсальный APK, без выбора архитектуры.
- `BebekonVPN-Portable-x64.zip` — переносимая Windows-сборка; для TUN требуется установка защищённой службы.

Что исправлено:

- **Мобильный интернет и раздача с телефона.** Прямой DNS и адрес VPN-сервера теперь разрешаются через DNS вашей сети (роутер, точка доступа телефона, оператор, «Частный DNS» Android). Раньше для этого использовался Cloudflare DoH, который у многих мобильных операторов замедляют или блокируют, из‑за чего подключение не проходило и появлялись таймауты. DNS для трафика через VPN по‑прежнему идёт через туннель (DoH).
- **Android выбирал мобильную сеть при включённом Wi‑Fi.** Ядро, пинги, загрузка подписок, карта и TrustTunnel теперь используют сеть, которую выбрал сам Android (Wi‑Fi раньше мобильных данных), а не первую попавшуюся.
- **Не нужно выключать и включать VPN на телефоне.** При переходе Wi‑Fi ↔ мобильные данные ядро видит реальную смену сети и сразу сбрасывает зависшие соединения. После глубокого сна (Doze) ядро возобновляет работу и пересоздаёт соединения, как это делает sing-box на компьютере после сна.
- **Точные пинги и без зависаний.** Проверка больше не загружает правила и гео-наборы, поэтому не тратит на них время таймаута. На Windows запуск ядра проверки (и проверка антивирусом) больше не засчитывается в пятисекундный таймаут, поэтому доступные серверы не помечаются «Таймаутом». Проверка, которая перестала отвечать, через несколько секунд завершается, а не висит «Проверка…» бесконечно. TCP-пинг на Windows без активного TUN идёт по обычному маршруту системы.
- **Проверка подключения на Windows** даёт медленной сети до 10 секунд и при неудаче пробует второй адрес, а не разрывает рабочий туннель.
- **Страна сервера без названия.** После успешного пинга клиент спрашивает службу геолокации через сам сервер и запоминает страну выхода VPN — флаг появляется без подключения. Ваш собственный IP при этом не передаётся. Работает, если включено «Местоположение на карте». Android также лучше распознаёт страну по названию: города (Amsterdam, Frankfurt…), коды вроде `DE-1` и падежи («в Германии»).

`update.json` подписан отдельным RSA-ключом Windows. Android APK подписан прежним сертификатом и устанавливается через стандартное подтверждение Android. Исходники изменённых ядер — `Bebekon-Core-Sources.zip`; контрольные суммы — `SHA256SUMS.txt` и `ANDROID-SHA256SUMS.txt`.
