# Bebekon VPN · Windows 0.1.24 и Android 0.1.11

Обновление стабильности сети. С этой версии релизы собираются и подписываются автоматически на GitHub, поэтому **ключи подписи сменились**. Один раз нужно установить новую версию вручную:

- **Android:** удалите прежнее Bebekon VPN и установите `Bebekon-Android.apk`. Поверх старого Android его не установит из‑за другой подписи. Подписки и правила нужно будет добавить заново.
- **Windows:** скачайте и запустите `BebekonVPN-0.1.24-Setup-x64.exe` поверх установленной версии — подписки, правила и настройки сохранятся. Старая версия сама это обновление не предложит.

Дальше обновления снова приходят автоматически.

Скачайте нужный файл:

- **Windows:** `BebekonVPN-0.1.24-Setup-x64.exe` — обычная установка или обновление.
- **Android 10+:** `Bebekon-Android.apk` — один универсальный APK, без выбора архитектуры.
- `BebekonVPN-Portable-x64.zip` — переносимая Windows-сборка; для TUN требуется установка защищённой службы.

Что исправлено:

- **Мобильный интернет и раздача с телефона.** Прямой DNS и адрес VPN-сервера теперь разрешаются через DNS вашей сети (роутер, точка доступа телефона, оператор, «Частный DNS» Android). Раньше для этого использовался Cloudflare DoH, который у многих мобильных операторов замедляют или блокируют, из‑за чего подключение не проходило и появлялись таймауты. DNS для трафика через VPN по‑прежнему идёт через туннель (DoH).
- **Android выбирал мобильную сеть при включённом Wi‑Fi.** Ядро, пинги, загрузка подписок, карта и TrustTunnel теперь используют сеть, которую выбрал сам Android (Wi‑Fi раньше мобильных данных), а не первую попавшуюся.
- **Не нужно выключать и включать VPN на телефоне.** При переходе Wi‑Fi ↔ мобильные данные ядро видит реальную смену сети и сразу сбрасывает зависшие соединения. После глубокого сна (Doze) ядро возобновляет работу и пересоздаёт соединения, как это делает sing-box на компьютере после сна.
- **Точные пинги и без зависаний.** Проверка больше не загружает правила и гео-наборы, поэтому не тратит на них время таймаута. На Windows запуск ядра проверки (и проверка антивирусом) больше не засчитывается в пятисекундный таймаут, поэтому доступные серверы не помечаются «Таймаутом». Проверка, которая перестала отвечать, через несколько секунд завершается, а не висит «Проверка…» бесконечно. TCP-пинг на Windows без активного TUN идёт по обычному маршруту системы.
- **Проверка подключения на Windows** даёт медленной сети до 10 секунд и при неудаче пробует второй адрес, а не разрывает рабочий туннель.
- **Ноутбук не подключался, хотя другие клиенты работают.** Таймаут соединения с сервером увеличен с 4 до 10 секунд (на нестабильном Wi‑Fi потеря одного пакета больше не обрывает подключение), адрес сервера сначала пробуется по IPv4. Поиск местоположения для карты больше не задерживает подключение дольше чем на 3 секунды. Режим «Совместимость» теперь также переключает встроенный сетевой стек — помогает, если VPN подключается, но сайты не открываются из‑за стороннего антивируса или фаервола. Адаптер виртуального коммутатора Hyper-V/WSL учитывается как основное подключение.
- **«Bebekon VPN уже запущен».** Повторный запуск (например, ярлыком, когда приложение уже стартовало вместе с Windows и сидит в трее) теперь просто открывает окно. При запуске с Windows окно больше не появляется, чтобы потом само спрятаться; автоподключение дожидается сети после загрузки и при неудаче повторяет попытку.
- **Правила сайтов в браузере с «Напрямую» (Android).** Если браузер (например, Яндекс Браузер) отмечен «Напрямую», а у вас есть правила сайтов через VPN, эти сайты теперь открываются через VPN, а всё остальное в браузере идёт напрямую. Другие приложения с «Напрямую» (банки, Госуслуги) по‑прежнему полностью вне VPN и не видят его.
- **Готовые наборы сервисов** теперь используют полные встроенные списки доменов вместо коротких ручных: Twitch (видео), Instagram и Facebook (картинки и видео), TikTok, WhatsApp и другие грузятся полностью; для Telegram добавлены IP-сети, по которым подключается приложение. Уже добавленные наборы можно добавить заново — повторы не создаются.
- **Добавлять сайты проще.** В правило можно вставить ссылку целиком (`https://www.youtube.com/watch?...`) или несколько через пробел — приложение само возьмёт домены. Сообщения об ошибках подключения на Windows подсказывают, что делать.
- **Страна сервера без названия.** После успешного пинга клиент спрашивает службу геолокации через сам сервер и запоминает страну выхода VPN — флаг появляется без подключения. Ваш собственный IP при этом не передаётся. Работает, если включено «Местоположение на карте». Android также лучше распознаёт страну по названию: города (Amsterdam, Frankfurt…), коды вроде `DE-1` и падежи («в Германии»).
