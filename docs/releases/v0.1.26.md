# Bebekon VPN для Windows 0.1.26

- Профили маршрутизации поддерживают Bebekon VPN, NetBird, Direct и Block. Сохранённые правила переносятся при обновлении.
- NetBird отображается отдельно. Корпоративный DNS и сетевые пробы используют подтверждённый интерфейс NetBird.
- Kill Switch применяет правила Windows Filtering Platform для IP/CIDR и полных путей приложений. Для доменного правила можно указать приложения, весь трафик которых должен использовать выбранный маршрут.
- Проверка из редактора показывает анализ черновика, доступность разрешённого маршрута и результат изолированной имитации отказа. Для подтверждения блокировки используется событие WFP.
- Резервные VPN проверяются в заданном порядке. При недоступности всех серверов этой политики ядро блокирует соединение.

Версия Android в этом выпуске — 0.1.12.
