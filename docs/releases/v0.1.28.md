# Bebekon VPN 0.1.28 для Windows и 0.1.13 для Android

## Windows

- На главной публичный и локальный IP скрыты. Нажмите на глаз рядом с нужным адресом. После смены адреса или повторного открытия страницы он снова скрыт.
- В разделе «Подключения» видны состояние Bebekon, выход через провайдера и доступные действия. Подробности интерфейсов и DNS можно раскрыть отдельно.
- Включить NetBird можно в «Настройки → Сеть». При обновлении интеграция сохраняется для профилей, где уже выбран NetBird. Когда интеграция выключена, клиент прекращает опрос NetBird, а сохранённые корпоративные правила блокируют соответствующий трафик и DNS.
- В списке правил отдельно показаны маршрут, активность правила и действие для остального трафика. На странице защиты доступны описание системной блокировки, число защищённых правил, тест WFP и журнал.
- Список серверов открывается без фоновой проверки всей подписки. Кнопка с молнией запускает проверку вручную. Автоматическую проверку можно вернуть в настройках сети. Одновременно выполняются до двух HTTPS-проверок.
- Импорт поддерживает сжатые HTTP-ответы и комментарии в списках ссылок. Для временной ошибки провайдера клиент показывает HTTP-код и предлагает повторить попытку позже.

## Android

- Нажатие на поле публичного IP открывает адрес. После смены сессии или адреса поле снова скрыто.
- В редакторе правила доступны два подписанных направления, «Через VPN» и «Напрямую». Редактирование сохраняет место правила среди записей с одинаковым приоритетом.
- Одновременно выполняются до двух HTTPS-проверок или четырёх TCP-проверок. При HTTP 429 и временных ошибках сервиса подписок приложение показывает причину.
