# Bebekon VPN для Windows 0.1.32

- Свои группы доменов. В «Правила → Мои группы» (значок папки) можно собрать домены под одним именем, задать цвет и значок, открыть группу и посмотреть, добавить или убрать домены, переименовать, дублировать и сразу создать из неё правило с нужным маршрутом. В правиле GeoSite группа выглядит как `my:название` и сочетается со встроенными наборами.
- Группами легко делиться: короткая ссылка `bebekon://group/…`, текст для чата или файл. Ссылка открывает предпросмотр, ничего не сохраняется без подтверждения. Импорт принимает и простой список доменов.
- Группа может обновляться по ссылке https:// (группа Bebekon, список доменов или формат v2fly) раз в 6 часов. Встроенный набор можно скопировать в свою группу и править.
- Несколько правил можно выделить и объединить в группу через меню правой кнопки. Если они ведут одинаково, их заменит одно правило на месте первого — приоритет не меняется.
- «Подключения → Недавние домены» показывает, куда ходили приложения за последние 15 минут, с маршрутом и программой. Выделите домены и нажмите «В группу»; похожие домены того же сайта или программы предлагаются сами. Список хранится только в памяти службы и очищается при отключении.
- Поиск домена в «Мои группы» показывает, в каких он группах и каким правилом и маршрутом обрабатывается.
- Приоритет правил стал понятнее: список по умолчанию открыт в порядке проверки, у каждого правила есть номер и стрелки вверх/вниз, перетаскивание — за ручку ⋮⋮ с линией вставки, а кнопка ⓘ объясняет приоритет на примере. Правила с системной защитой показаны отдельной группой сверху.
- NetBird подключается из Bebekon без окна NetBird: если сеанс истёк, страница входа открывается в браузере. Новая настройка «Подключать NetBird автоматически» включает его при запуске Bebekon и при подключении VPN.
- Развёрнутое на весь экран окно больше не уходит под панель задач Windows; скрываемая панель задач остаётся доступной.

Версия Android в общем канале — 0.1.13.
