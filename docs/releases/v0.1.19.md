# Bebekon VPN · Windows 0.1.19 и Android 0.1.6

Обновление безопасности. Подписки, правила и настройки сохраняются при установке поверх прежней версии; ключи подписи не менялись.

Скачайте нужный файл:

- **Windows:** `BebekonVPN-0.1.19-Setup-x64.exe` — обычная установка или обновление.
- **Android 10+:** `Bebekon-Android.apk` — один универсальный APK, без выбора архитектуры.
- `BebekonVPN-Portable-x64.zip` — переносимая Windows-сборка; для TUN требуется установка защищённой службы.

Что защищено:

- Android больше не принимает команды включения/отключения VPN от посторонних приложений через launcher.
- Проверка сертификата VPN-сервера обязательна. Узлы с `insecure`/`skip-cert-verify` отклоняются, включая сохранённые старой версией. Если провайдер выдаёт такой узел, запросите у него безопасную конфигурацию.
- Удалённые Windows-подписки требуют HTTPS. Ограничены сложность JSON/YAML и параметры встроенных Shadowsocks-плагинов; запрещены ссылки на файлы сертификатов из подписки.
- Windows проверяет владельцев и права файлов службы, рабочее хранилище и ссылки в путях до запуска привилегированного ядра.
- Android повторно проверяет SHA-256 APK перед установкой, ограничивает длительность загрузок и скрывает секреты в диагностике.
- Пересобраны сетевые Go-ядра с исправленными зависимостями; Windows включает .NET 10.0.12.

Проверки и ограничения описаны в [отчёте безопасности](../SECURITY-AUDIT.md) и [VALIDATION.md](../VALIDATION.md). Это не обещание абсолютной защиты: остаётся непроверенный состав исправлений C++ TrustTunnel HTTP/2 и отсутствует независимый аварийный kill switch Windows.

`update.json` подписан отдельным RSA-ключом Windows. Android APK подписан прежним сертификатом и устанавливается через стандартное подтверждение Android. Исходники изменённых ядер — `Bebekon-Core-Sources.zip`; контрольные суммы — `SHA256SUMS.txt` и `ANDROID-SHA256SUMS.txt`.
