# Bebekon VPN для Windows 0.1.34

- Папки для правил. Правила можно сложить в папку: она сворачивается и раскрывается, у неё есть цвет и значок. Папка — только удобная обёртка: каждое правило внутри работает по своему маршруту (VPN, напрямую, NetBird, блокировка). Правила папки стоят подряд, номера приоритета идут по порядку; папку целиком можно поднять или опустить стрелками.
- Положить правило в папку можно в редакторе правила (новое поле «Папка»), кнопкой «+» на папке, перетаскиванием на папку, через меню правой кнопки («Переместить в папку», «Новая папка из выбранных») или отметив правила в редакторе папки.
- Папками можно делиться: короткая ссылка `bebekon://folder/…`, текст для чата или файл. Перед добавлением Bebekon показывает, что внутри. Привязки к вашим серверам не передаются.
- Группы доменов из 0.1.32–0.1.33 автоматически превращаются в папки с обычными правилами — маршруты не меняются.
- «Защита выбранных адресов» стала удобнее: выберите «Сайт» или «IP или подсеть», добавьте значение, удаляйте записи крестиком или добавьте адреса из правил и папок.
- «Подключения → Недавние домены → Создать правило» открывает обычный редактор правила с выбранными доменами.

Версия Android в общем канале — 0.1.13.
