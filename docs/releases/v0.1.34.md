# Bebekon VPN для Windows 0.1.34

Изменения с 0.1.31:

**Стабильность и сеть**
- Исправлены случайные обрывы сайтов, которые идут напрямую (npmjs.com, магазин расширений VS Code, Outlook и другие с адресами IPv6): «Соединение сброшено». Если у вашей сети нет IPv6, Bebekon работает только по IPv4 и отдаёт приложениям только адреса IPv4.
- Развёрнутое на весь экран окно больше не уходит под панель задач.
- Установщик повторно останавливает службу перед заменой файлов: обновление больше не падает с «Отказано в доступе», если приложение было открыто.

**Папки для правил**
- Правила можно сложить в папку с цветом и значком; папка сворачивается и раскрывается. Это только удобная обёртка: каждое правило внутри работает по своему маршруту. Правила папки стоят подряд, папку можно поднять или опустить стрелками.
- Положить правило в папку: поле «Папка» в редакторе правила, «+» на папке, перетаскивание на папку или меню правой кнопки («Переместить в папку», «Новая папка из выбранных»).
- Папками можно делиться ссылкой `bebekon://folder/…`, текстом или файлом; перед добавлением видно, что внутри. Привязки к вашим серверам не передаются.

**Правила**
- Порядок проверки стал понятнее: список по умолчанию открыт по приоритету, у правил есть номера и стрелки, перетаскивание — за ручку ⋮⋮ с линией вставки, кнопка ⓘ объясняет приоритет на примере.
- «Подключения → Недавние домены» показывают, куда ходили приложения за 15 минут, с маршрутом и программой; «Создать правило» открывает редактор правила с выбранными доменами. Список хранится только в памяти службы.
- «Защита выбранных адресов»: выберите «Сайт» или «IP или подсеть», добавьте значение, удаляйте крестиком или добавьте адреса из правил и папок.

**Обход блокировок без VPN**
- Zapret в настройках: «Сеть → Zapret · обход блокировок без VPN». Один раз импортируйте папку zapret (например, flowseal/zapret-discord-youtube) — Windows спросит права администратора, Bebekon скопирует zapret в защищённую папку службы. Дальше переключатель включает его вместе с Bebekon.
- «Подобрать» перебирает профили (general, ALT, FAKE TLS…), открывает YouTube и Discord напрямую и оставляет самый быстрый рабочий. У каждого профиля есть понятное описание. Адреса ваших VPN-серверов Bebekon сам исключает из zapret.
- «Обход замедления» больше не дробит все прямые сайты: только YouTube, Discord, X, Instagram, Facebook, TikTok, ваши правила Direct и ваш список. Можно выбрать способ, а «Проверить сайт» показывает, что работает у вашего провайдера, или предлагает правило через VPN, если сайт заблокирован полностью.

**NetBird**
- Подключается из Bebekon без окна NetBird; если сеанс истёк, страница входа открывается в браузере. Настройка «Подключать NetBird автоматически» включает его при запуске Bebekon и подключении VPN.
