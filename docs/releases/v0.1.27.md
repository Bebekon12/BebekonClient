# Bebekon VPN для Windows 0.1.27

- Bebekon определяет активный NetBird при запуске TUN, даже если в профиле нет правил для NetBird.
- DNS-запросы к точным именам серверов управления NetBird работают до появления корпоративного туннеля. Транспорт зарегистрированной службы использует основной интерфейс.
- Остальные корпоративные домены и соединения продолжают следовать правилам профиля.
