## Bebekon VPN 0.1.9 · Windows x64

Первый релиз на GitHub с обновлениями из приложения.

- Обновления через **Настройки → Обновления**: автоматическая проверка при запуске и каждые 6 часов, установка кнопкой **«Обновить и перезапустить»**.
- Подпись списка обновлений и SHA-256 установщика проверяются до запуска. Ссылка на пакет закреплена за версией релиза.
- Подписки, правила, выбранный сервер и настройки сохраняются при обновлении. Для обновления службы Windows запросит UAC.
- Зелёные, оранжевые и красные значения пинга больше не тускнеют при проверке; таймаут после пяти секунд остаётся красным.
- Новая кнопка подключения: тёмная объёмная поверхность, градиентный ободок и мягкая подсветка.
- Включены реальные счётчики трафика, список серверов на главной, стабильный выбор сервера при обновлении подписки и исправления повторных подключений после изменения правил.

### Установка и переход

**BebekonVPN-0.1.9-Setup-x64.exe** — рекомендуемый установщик. Закройте старое приложение через трей и установите поверх него, без удаления пользовательских данных. .NET отдельно устанавливать не требуется.

**BebekonVPN-Portable-x64.zip** — переносимая сборка. Для режима TUN всё равно требуется защищённая служба Windows; приложение предложит установить её с UAC.

Версия 0.1.8 на компьютере сборки увидит 0.1.9 через локальный канал. Для перехода через интернет задайте источник в **Настройки → Обновления → Источник обновлений**:

`https://github.com/Bebekon12/BebekonClient/releases/latest/download/update.json`

В 0.1.9 этот адрес включён по умолчанию. На версиях до 0.1.8 сначала нужен однократный запуск установщика.

### Проверки

150 автоматических тестов; проверка интерфейса собранной версии, подписанного списка обновлений и контрольных сумм пакетов. Полная установка обновления с UAC и физические TUN-сценарии на разных конфигурациях Windows остаются в [матрице ручной проверки](https://github.com/Bebekon12/BebekonClient/blob/main/docs/VALIDATION.md).
