# Bebekon VPN для Windows 0.1.30

- Подключение больше не обрывается каждый час при автообновлении подписки. Некоторые провайдеры выдают для того же сервера новое доменное имя при каждой загрузке. Работающий туннель теперь сохраняет текущий адрес, а новый используется при следующем подключении. Изменение ключей или параметров сервера по-прежнему переподключает туннель.
- Если ядро VPN завершилось само или перезапуск после изменения настроек не удался, Bebekon переподключается автоматически: через 2, 4, 8, 15, а затем каждые 30 секунд. Пока сети нет, попытки не расходуются. Защита при обрыве VPN продолжает блокировать трафик между попытками. Кнопка «Отменить» прекращает переподключение. Раньше VPN в таких случаях оставался выключенным до ручного подключения.
- Кратковременная задержка ответа службы больше не переводит подключение в ошибку и не останавливает обновление состояния.
- Запуск ядра может занимать до 40 секунд вместо 15. Это нужно, когда Windows медленно пересоздаёт адаптер TUN сразу после предыдущего подключения.
- Изменения маршрутов NetBird перезапускают туннель только если сохраняются при двух проверках подряд. Профиль без правил NetBird реагирует только на появление или смену интерфейса NetBird.

Версия Android в общем канале — 0.1.13.
