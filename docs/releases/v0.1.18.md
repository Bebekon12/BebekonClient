Windows 0.1.18 и Android 0.1.3 — один общий релиз.

### Android
- Исправлено автоматическое разделение приложений: системный список выбранных пакетов сохраняется до преобразования веб-приложений в правила сайтов. Неотмеченные приложения сохраняют обычную сеть и DNS.
- Добавление правил сайтов/наборов к выбранным приложениям больше не включает общий туннель без явного выбора. Настройка «Правила сайтов во всех приложениях» включает этот режим отдельно; при правилах только для сайтов он нужен автоматически.
- Явное «Напрямую» полностью исключает приложение из туннеля: правило сайта `2ip` не может отправить трафик через VPN из такого браузера. Для выборочных сайтов во всех браузерах включите общий режим сайтов и уберите явное исключение у нужного браузера. Этот режим создаёт системную VPN-сеть; отдельную невидимую VPN-сеть для каждого сайта Android не предоставляет.
- В общем режиме сайтов неприменённые DNS-запросы идут через прямой резолвер, а совпавшие правила используют свой DNS. В журнале показана фактически созданная область туннеля без ссылок подписок и ключей.
- Распознаваемое веб-приложение использует сеть своего браузера; остальные приложения больше не захватываются из-за преобразования его правила.
- Зелёные результаты поднимаются в списке сразу по мере проверки. Пинг выполняется в четыре параллельных проверки, таймаут активной проверки — 5 секунд. Выбранный сервер сохраняется.

### Windows
- Главная карта увеличена: выше блок, крупнее страны и световая дуга. Зелёная точка подключения стоит рядом с «Ваше подключение», вместо отдельной точки над картой.
- Результаты пинга сортируются во время проверки; хорошие серверы появляются сверху, выбранный сервер сохраняется. При массовой проверке автоматически выбирается сортировка по пингу.
- HTTPS GET/HEAD измеряют один полный запрос вместо трёх последовательных. Одновременно выполняются до шести проверок с прежним таймаутом 5 секунд на активную проверку.
- Запуск и очистка процессов проверки выполняются вне потока интерфейса. Закрытие Windows Job уже завершает дерево ядра; повторный дорогой поиск дочерних процессов убран.

### Скачать
- **Windows:** `BebekonVPN-0.1.18-Setup-x64.exe` — установка или обновление поверх текущей версии. Portable ZIP — для запуска из папки.
- **Android 10+:** единственный `Bebekon-Android.apk`. Android 0.1.2 предложит обновление внутри приложения; подтверждение установки остаётся системным. Подпись прежняя, настройки сохраняются.
- Архив исходников ядра и контрольные суммы для обычного запуска скачивать не нужно.

### Проверки и границы
250 тестов Windows, 47 тестов Android и расширенная проверка настоящего туннеля на Android 15 прошли (9 тестов; необязательные проверки провайдера и будущего APK без дополнительных файлов не повторялись). Проверка интерфейса Windows прошла, Android Lint — без ошибок. Подпись APK и выравнивание 16 KiB проверены.

В опубликованной подписанной 0.1.2 воспроизведено ошибочное включение невыбранного приложения в туннель при правиле веб-приложения. После обновления тем же подписанным APK до 0.1.3 настройки сохранились, а невыбранное приложение использовало обычную сеть и получило HTTP 200. Физический телефон пользователя не подключён; это не утверждение о воспроизведении именно его страницы Яндекса или проверки Госуслуг.
