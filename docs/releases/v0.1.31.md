# Bebekon VPN для Windows 0.1.31

- Пинг больше не скачет между сотнями миллисекунд и секундами. Раньше значение было одним «холодным» HTTPS-запросом: в него входили DNS, подключение и рукопожатие TLS/Reality, и потеря одного пакета добавляла 1–3 с. Теперь первый запрос только подтверждает доступность сервера, а показывается лучший из повторных запросов по тому же соединению, то есть задержка через сервер без рукопожатий. Методы TCP и ICMP не изменились.
- Новая настройка «Сеть → Автопинг текущего сервера»: выключен, каждые 5, 10 или 30 секунд, раз в минуту. По умолчанию — каждые 10 секунд. Пока VPN подключён, задержка измеряется через работающий туннель, без запуска дополнительного ядра и с ничтожным трафиком; значение видно на главной и внизу боковой панели. Показывается медиана трёх последних замеров, «Таймаут» — только после двух неудач подряд. Без подключения выбранный сервер проверяется не чаще раза в 30 секунд.
- Кнопка обновления пинга на главной при подключении измеряет задержку через сам туннель.

Версия Android в общем канале — 0.1.13.
