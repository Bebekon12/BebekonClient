Windows 0.1.17 и Android 0.1.2 — один общий релиз.

### Windows
- На главной странице появилась карта мира со страной сервера и световой дугой. Снеговик в прежней шляпе, компоновка и управление сохранены.
- Начало дуги — примерное место по обычному IP. Без GPS и сохранения координат; можно отключить в настройках оформления. Если определить место не удалось, выдуманная точка не показывается.
- Графики загрузки и отправки хранят последние 120 измерений.

### Android
- Обновления внутри приложения: предложение «Обновить / Позже», загрузка с прогрессом, проверка SHA-256 и подписи APK, затем системное подтверждение установки.
- Исправлена изоляция приложений в режиме «По правилам»: при правилах только для приложений невыбранные приложения остаются на обычной сети со своим DNS. DNS выбранных приложений идёт через VPN, включая запросы системного резолвера без исходного UID. Явные исключения «Напрямую» обходят туннель и при смешанных правилах сайтов/приложений.
- Уже добавленные приложения отмечены галочками. Сохранение выбора сохраняет правила сайтов и применяет изменения одним переподключением.
- Текст главных карточек выровнен по центру. Под загрузкой и отправкой указан объём в ГБ за сессию. Подняв шторку, можно увидеть увеличенные графики за последние две минуты; история собирается и на других экранах. Объём сохраняется при применении правил.
- Световая дуга начинается от примерного текущего места по обычному IP и ведёт к стране подключения. Учтены тёмная/светлая темы и отключение анимаций/определения места.
- Расширенные настройки с поиском: оформление, правила, LAN, DNS, MTU, повтор подключения, системный постоянный VPN, батарея, плитка шторки, пинг, диагностика сайта, уведомления, подписки, обновления и журнал.
- Ошибку подключения можно повторить до трёх раз без смены сервера. Отмена из приложения или плитки шторки отменяет отложенную попытку.
- Для распознаваемых Chromium веб-приложений учитывается, что запросы делает браузер; доступны пояснение и готовый набор OpenAI / ChatGPT.

### Что скачать
- **Android 10+: `Bebekon-Android.apk`** — один APK для всех поддерживаемых архитектур.
- **Windows: `BebekonVPN-0.1.17-Setup-x64.exe`** — установщик. Уже установленный клиент получит предложение обновления.
- `BebekonVPN-0.1.17-Portable-x64.zip` — вариант Windows без установщика приложения.
- Архив Core Source и файлы контрольных сумм скачивать для обычного запуска не нужно.

Android 0.1.1 нужно один раз обновить этим APK вручную, чтобы появились обновления из приложения. Подпись прежняя; подписки, выбор сервера и настройки сохраняются. Android всё равно требует системное подтверждение установки.

Конкретный сбой Яндекса и установленного ChatGPT на физическом телефоне здесь не воспроизведён. Исправлены найденные ошибки нашей маршрутизации и DNS; результат на этом устройстве нужно проверить после обновления. Системная опция Android «Блокировать соединения без VPN» блокирует приложения-исключения; клиент теперь сообщает об этом конфликте.

### Проверки
Windows: 250 тестов пройдены, один внешний TrustTunnel-тест требует отдельного стенда; полный набор проверок интерфейса готовой сборки выполнен без запуска установщика. Android: 45 JVM-тестов и 9 проверок на эмуляторе пройдены, Lint без ошибок. Проверены настоящая маршрутизация отдельного приложения, передача данных более 5 секунд, счётчики/перезагрузка правил, отмена повторов, обновление APK и сохранение подписки/настроек при установке поверх 0.1.1. Подписанный релизный APK также передал HTTPS-запрос отдельного приложения через VPN с HTTP 200. Физический телефон не подключён.
