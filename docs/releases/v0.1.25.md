# Bebekon VPN · Windows 0.1.25 и Android 0.1.12

Новые возможности для повседневного использования. Обновление приходит автоматически; подписки, правила и настройки сохраняются.

Скачайте нужный файл:

- **Windows:** `BebekonVPN-0.1.25-Setup-x64.exe` — обычная установка или обновление.
- **Android 10+:** `Bebekon-Android.apk` — один универсальный APK.
- `BebekonVPN-Portable-x64.zip` — переносимая Windows-сборка; для TUN требуется установка защищённой службы.

Что нового:

- **Авто — самый быстрый сервер.** Кнопка «Авто» в списке серверов (на Android — и на главном экране). VPN сам измеряет серверы из видимых подписок, использует самый быстрый работающий и переключается на другой, если сервер перестал отвечать или сменилась сеть. На главном экране видно, какой сервер выбран сейчас. Выбранный вручную сервер проверяется первым. Серверы XHTTP и TrustTunnel в автовыборе не участвуют.
- **Трафик и срок подписки.** Если провайдер их сообщает (как для Happ, Clash, Remnawave, Marzban), на карточке подписки показаны остаток трафика и дата окончания, объявление провайдера и кнопки «Поддержка» и «Сайт провайдера». За 3 дня до окончания или при остатке меньше 10% появляется предупреждение — заранее, а не когда VPN внезапно перестанет работать.
- **Подписки обновляются сами** — с интервалом, который задал провайдер, иначе раз в 12 часов, в том числе при долгом подключении. Если обновить не удалось, прежние серверы сохраняются, а попытка повторяется через час.
- **Резервная копия.** В настройках можно сохранить и восстановить копию. Один файл подходит и для Windows, и для Android: подписки (серверы скачиваются заново), правила сайтов, IP и гео-наборов в том же порядке; правила программ и настройки восстанавливаются на той же платформе. Восстановление только добавляет недостающее и ничего не удаляет. В файле есть ссылки подписок — храните его в надёжном месте.
- **Ссылки «Добавить в Bebekon».** Провайдер может разместить ссылку `bebekon://add/<ссылка подписки>` (или `bebekon://import?url=…`). Она открывает приложение с уже вставленной подпиской — добавляете вы сами, ничего не подключается без вашего нажатия. Принимаются только https- и прокси-ссылки.
- **Обход замедления сайтов без VPN** (настройка, по умолчанию выключена). Для сайтов и программ, которые по вашим правилам идут напрямую, начало TLS-соединения делится на части — помогает, если провайдер замедляет их по имени. Трафик через VPN не меняется.
- **Защита от утечек на Windows (kill switch)** (настройка, режим TUN, по умолчанию выключена). Пока VPN включён, переподключается или если ядро внезапно остановилось, интернет вне VPN заблокирован; роутер, принтер и другая локальная сеть доступны. Снимается кнопкой «Отключить». Блокировку держит Windows Filtering Platform в динамическом сеансе, как в WireGuard: если служба остановится или завершится со сбоем, Windows убирает её сама — компьютер не останется без интернета. На Android для этого есть системная настройка «Постоянный VPN» → «Блокировать соединения без VPN» (кнопка в настройках приложения).
- **Android сам замечает «зависший» туннель.** Если приложения отправляют данные, а ответа нет, клиент проверяет связь через сам туннель и после двух неудачных проверок подряд переподключается (не чаще раза в 5 минут; не во сне и не без сети). Обычный и простаивающий туннель не проверяется — трафик и батарея не тратятся. Публичный IP на главном экране теперь берётся через работающий туннель.

Контрольные суммы — `SHA256SUMS.txt` и `ANDROID-SHA256SUMS.txt`; исходники изменённых ядер — `Bebekon-Core-Sources.zip`.
