Windows 0.1.18 и Android 0.1.4 — общий релиз. В этой версии обновляется Android; файлы Windows сохранены с прежними контрольными суммами.

### Android

- Исправлен VPN по умолчанию у браузера, который автоматически попал в туннель из-за выбранного веб-приложения. Сайт веб-приложения и другие сайты из правил используют VPN; остальное в этом браузере идёт напрямую. Явный выбор всего браузера «Через VPN» по-прежнему отправляет его трафик через VPN.
- Обычные выбранные приложения сохраняют свой VPN-маршрут. Невыбранные приложения остаются вне системного туннеля, пока выключена настройка сайтов во всех приложениях.
- В выборе приложений видно домен веб-приложения и браузер, который обслуживает его сетевые запросы. Для ChatGPT доступен набор OpenAI / ChatGPT с доменами авторизации и ресурсов.
- Уточнено описание «Правила сайтов во всех приложениях»: выключенная настройка не может обработать сайт в браузере, который полностью находится вне туннеля. Явное «Напрямую» исключает приложение целиком, включая правила сайтов.
- Добавлены «Диагностика маршрутизации» и «Журнал маршрутов» в Настройки → Проверки. Запись выключена по умолчанию; последние 200 строк хранятся в памяти телефона. Домены, выбранные маршруты и ошибки доступны для копирования; ссылки подписок и данные доступа скрываются. Журнал может содержать посещённые сайты.

### Скачать

- **Android 10+:** единственный `Bebekon-Android.apk`, подписанный прежним ключом. Обновление из приложения или установка поверх текущей версии сохраняет настройки.
- **Windows:** прежние `BebekonVPN-0.1.18-Setup-x64.exe` и Portable ZIP. Нового обновления Windows в этом релизе нет.
- Исходники ядра и контрольные суммы для обычного запуска скачивать не нужно.

### Проверки и границы

49 модульных тестов Android прошли. В настоящем Android VpnService проверяются маршруты HTTPS из отдельного тестового UID, играющего роль браузера веб-приложения: совпавший сайт через VPN, другой сайт напрямую, смешанный выбор с обычным приложением и явный выбор всего браузера. Проверка также охватывает потоки, переподключение и отмену повторных попыток.

Обрыв Яндекса на физическом телефоне при общем режиме сайтов пока не воспроизведён и не объявляется исправленным. Для проверки нужны записи нового журнала во время ошибки.
