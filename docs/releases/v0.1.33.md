# Bebekon VPN для Windows 0.1.33

- Zapret прямо в настройках: «Сеть → Zapret · обход блокировок без VPN». Один раз импортируйте папку zapret (например, flowseal/zapret-discord-youtube) — Windows спросит права администратора, Bebekon скопирует zapret в защищённую папку службы. Дальше переключатель включает и выключает zapret вместе с Bebekon без окон и запросов.
- «Подобрать автоматически»: Bebekon по очереди включает каждый профиль (general, ALT, FAKE TLS…), открывает YouTube и Discord напрямую и оставляет самый быстрый из тех, что открыл все сайты. У каждого профиля есть понятное описание его способа обхода.
- Адреса ваших VPN-серверов Bebekon сам добавляет в исключения zapret и проверяет их при каждом подключении, чтобы zapret не трогал соединение VPN.
- «Обход замедления» больше не дробит все прямые сайты: по умолчанию только YouTube, Discord, X, Instagram, Facebook, TikTok, ваши правила Direct и ваш список. Можно выбрать способ — записи TLS (+≈50 мс), сегменты TCP или оба. Кнопка «Проверить сайт» показывает, что работает на вашем провайдере, а если сайт заблокирован полностью — предлагает правило «через VPN».
- Группы стали группами правил: в группе могут быть домены, слова (`keyword:`) и IP/подсети. В редакторе группы и в «Защите выбранных адресов» можно добавить содержимое из своих групп и текущих правил.

Версия Android в общем канале — 0.1.13.
