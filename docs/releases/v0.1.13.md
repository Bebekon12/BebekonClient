## Bebekon VPN 0.1.13

- Исправлена загрузка подписок SnowVPN и других VLESS-провайдеров с привязкой к устройству: клиент передаёт постоянный HWID и информацию о версии Windows. Исходный идентификатор Windows провайдеру не отправляется; обновление и переустановка приложения на той же Windows сохраняют HWID.
- Добавлен импорт **Clash/Mihomo YAML и JSON**, в том числе Base64. Сохраняются параметры VLESS: TLS/Reality, TCP, gRPC, WebSocket, HTTP/2, HTTPUpgrade, SNI, ALPN, flow и параметры UDP. Прежние VLESS-ссылки и Xray JSON продолжают работать.
- Понятные сообщения для лимита устройств, отказа HWID, веб-страницы вместо подписки и информационных заглушек. Такие записи больше не предлагаются как рабочие серверы. Таймаут загрузки охватывает весь ответ.
- Новая подписка открывается с пустым названием. Оно необязательно: если его не задать, используется домен ссылки. При редактировании сохраняется своё имя.
- Правила маршрутизации, DNS, выбранный сервер и избранное сохраняются. Вкладка подписок объясняет поддерживаемые форматы и передачу HWID. [Подробности импорта](https://github.com/Bebekon12/BebekonClient/blob/main/docs/SUBSCRIPTIONS.md).

В предыдущей версии откройте **Настройки → Обновления → Проверить**, затем нажмите **«Обновить»**. Переустановка с удалением приложения не нужна. Для первой установки — **BebekonVPN-0.1.13-Setup-x64.exe**.

Протоколы, отличные от VLESS, внешние `proxy-providers` и некоторые дополнительные параметры пока не поддерживаются; клиент показывает причину. Правило провайдера `MATCH` означает весь трафик через выбранный сервер — для этого выберите режим **«Весь ПК»**.

Проверки: 208 автоматических тестов, проверка конфигураций официальным sing-box, импорт подписок с HWID и без него, реальные HTTPS-запросы через TCP/TLS и gRPC/Reality, полная проверка интерфейса готовой сборки. Установка с UAC и реальная маршрутизация TUN остаются в [матрице ручной проверки](https://github.com/Bebekon12/BebekonClient/blob/main/docs/VALIDATION.md).
