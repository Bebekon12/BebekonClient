Flags are bundled locally as 80-pixel PNG images, with English and Russian country labels.
Source: [Flagpedia / FlagCDN](https://flagpedia.net/download/api), downloaded 2026-10-03.
FlagCDN describes the source artwork as Wikimedia Commons vector files and provides free programmatic downloads.
No requests to FlagCDN are made by the installed application. A label identifies the country stated by the provider, not verified IP geolocation.
